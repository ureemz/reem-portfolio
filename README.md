# معرض أعمال ريم محمد عبدالله

موقع معرض أعمال (Portfolio) تفاعلي بالعربية، مبني بـ HTML وCSS وJavaScript فقط — بدون أي مكتبات أو خطوات بناء. يعمل مباشرة عند فتح `index.html` أو عبر أي استضافة ثابتة مثل GitHub Pages.

## الملفات

```
index.html              ← هيكل الصفحة والنصوص الثابتة
assets/
  css/style.css         ← التصميم، الوضع الليلي/النهاري، التجاوب
  js/data.js            ← بيانات المشاريع والروابط (عدّلي من هنا)
  js/main.js            ← التفاعلات (فلترة، نافذة التفاصيل، الوضع الليلي…)
  projects/             ← صور معاينة المشاريع
  favicon.svg
```

## كيف أعدّل روابط أعمالي؟

كل شيء موجود في **`assets/js/data.js`**:

```js
{
  id: "raem",
  title: "RAËM — عبايات نسائية فاخرة",
  category: "متجر إلكتروني",
  filters: ["ecommerce", "design"],
  description: "وصف قصير يظهر في البطاقة",
  longDescription: "وصف أطول يظهر في نافذة التفاصيل",
  image: "assets/projects/raem.jpg",
  url: "https://ureemz.github.io/raem-abaya/",
  displayUrl: "ureemz.github.io/raem-abaya",
  tags: ["HTML5", "CSS3", "JavaScript"],
  role: "تصميم وتطوير كامل",
  year: "2026",
  accent: "#c9a36a",
  highlights: ["ميزة أولى", "ميزة ثانية"]
}
```

- غيّري `url` إلى الرابط الجديد — سيُفتح تلقائيًا في تبويب جديد (`target="_blank"`).
- غيّري `image` بعد وضع صورة جديدة داخل `assets/projects/`.
- لإضافة مشروع: انسخي الكائن كاملًا، غيّري `id` إلى قيمة جديدة، وأضيفيه داخل `projects`.
- `filters` تحدد التصنيفات التي يظهر تحتها المشروع:
  - `ecommerce` = متاجر إلكترونية
  - `personal` = مواقع شخصية
  - `design` = تصميم وتجربة
- التصنيفات نفسها موجودة في `filters` أعلى الملف، ويمكن إضافة تصنيف جديد وربطه بأي مشروع.

## تعديل بيانات التواصل

من نفس الملف `assets/js/data.js`:

```js
phone: "0542308267",
phoneIntl: "+966542308267",
whatsapp: "966542308267",
github: "https://github.com/ureemz",
```

ثم ابحثي في `index.html` عن `966542308267` و`0542308267` لتحديث الروابط الظاهرة في الهيدر، قسم التواصل، والفوتر.

نموذج التواصل لا يحتاج خادمًا: عند الإرسال يتم تجهيز الرسالة وفتح واتساب مباشرة.

## إضافة صور المشاريع

1. ضعي الصورة داخل `assets/projects/`.
2. يفضّل أن تكون بنسبة `16:10` وبعرض 1280px لتظهر بشكل مثالي.
3. حدّثي قيمة `image` في `data.js`.

## تغيير الألوان

كل الألوان في بداية `assets/css/style.css` داخل `:root` (الوضع الليلي) و`html[data-theme="light"]` (الوضع النهاري):

```css
--gold: #d6b489;   /* اللون الأساسي */
--bg: #07080a;     /* الخلفية */
--text: #f4f0e8;   /* لون النص */
```

## تشغيل الموقع محليًا

يمكن فتح `index.html` مباشرة. ويُفضّل تشغيل خادم محلي بسيط:

```bash
python -m http.server 8000
```

ثم افتحي `http://localhost:8000`.

## النشر على GitHub Pages

1. أنشئي مستودعًا جديدًا على GitHub (مثل `reem-portfolio`).
2. ارفعي محتويات المجلد (وليس المجلد نفسه).
3. من المستودع: **Settings → Pages → Branch: main / root → Save**.
4. سيصبح الرابط: `https://ureemz.github.io/reem-portfolio/`.

## ملاحظات

- الصور الحالية لقطات شاشة حقيقية من المشاريع الأربعة.
- الموقع يحترم إعداد «تقليل الحركة» في النظام، ويدعم لوحة المفاتيح والتنقل بالشاشة القارئة.
- الوضع الليلي هو الافتراضي، واختيار الزائر للوضع النهاري يُحفظ في المتصفح.
